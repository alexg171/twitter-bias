# data/

Raw input files (not committed — see `.gitignore`):

| File | Description |
|------|-------------|
| `twitter_trending_4yr.csv` | 694,930 unique topic-day observations, Oct 2020–Oct 2024 |

Generate these by running `src/scraper.py` and `src/reddit_category_pull.py`, or drop in your own copies before running `src/run_all.bat`.
